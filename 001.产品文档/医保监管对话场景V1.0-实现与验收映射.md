# 医保监管对话场景 V1.0 实现与验收映射

需求依据：[浦东新区医保智能体-对话场景-需求说明V1.0](浦东新区医保智能体-对话场景-需求说明V1.0.md)。原需求文件保持不变。

## 实现范围

- 浦东医保监管助手名称、六关键词介绍、12家/37次/5次首页指标。
- 三个快捷场景；原接入审核、台账查询、评测、监控等对话入口与执行逻辑已替换。
- 场景一：A风险概况、B检查进度、C风险进度交叉；支持图表下钻、机构/批次列表和时效查询。
- 场景二：机构画像必经、B纵向溯源与C横向对标可自由切换、监管建议、报告预览和对话修改。
- 场景三：检查定位、行为分析、历史/同类比较、多维指标、核查建议及报告。
- 7条历史会话与3组自动化任务及模板同步替换。
- Word为实际OOXML .docx，包含分析图和检查表；PDF包含中文章节和分析图。

## 演示数据统一口径

1. 监管数据固定为2026-11-09快照，以保持文档“11月5日进入阶段，停留4天”的示例；不是实时业务查询。
2. 124家机构：高12、中28、低84。上期为高10、中31、低83；5家上升，另4家中风险降为低风险，保证环比自洽。
3. 37次未办结，7次当前超期，其中5次本月新增；12家高风险机构中7家存在未办结，关联9个批次。
4. 浦东新区中医医院代码PDYB-310115-001，共8次有效检查，历次算术均分50.63，时间递减加权机构指数58.00（中风险）；最新单次指数78.00，两者分开呈现。
5. FXJC-2026-011唯一归属浦东新区中医医院，当前阶段固定为网审分工。文档中“A机构”按示例别名映射该院；高风险任务清单实际从高风险机构关联批次选取，避免把中风险机构写成高风险。文档另一示例将同批次写为形成结果阶段，此处不采用矛盾状态。
6. 最近5年为2022—2026年；2021年作为历史对照保留单独入口，不将6年范围称为5年。
7. 文档XX占位内容用统一虚构样本补齐；具体项目为明确标注的演示项目，未虚构真实患者记录。
8. 风险模型展示既定评分结果与公式、参数版本；尚未接入真实归一化参数、评分引擎和监管数据服务，演示贡献值不可作为正式评分权重。
9. 报告仅写入本轮已完成分支；未开展的分析明确标注，不补造比较结论。
10. 自动化历史条目按原需求保留固定日期及时间标签，作为静态演示记录；不会真实推送消息。

## 验证方式

在`002.前端代码`下执行：

```sh
npm run build
node tests/regulator.e2e.mjs
node tests/regulator-render.mjs
```

两项浏览器验证需先启动3001端口开发服务。主测试校验原文55条问句、计数、三场景追问、机构与批次不匹配、报告覆盖范围、真实Word/PDF下载、会话恢复与窄屏无横向溢出；渲染测试逐条检查55条结果组件。验收截图与导出样本写入`/tmp/pudong-regulator-qa/`。
