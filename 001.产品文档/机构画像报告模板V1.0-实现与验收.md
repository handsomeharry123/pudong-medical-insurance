# 机构画像报告模板 V1.0 实现与验收

依据：`机构画像报告模板（业务侧）-V1.0.md`。本次调整覆盖画像报告内容、报告卡目录、在线预览、Word 及 PDF；不修改单次检查报告的业务模板。

## 模板映射

| 模板 | 实现 |
| --- | --- |
| 标题及报告信息 | 机构名称＋医疗机构监管画像报告；报告时间范围、数据更新至、生成时间、机构代码、结算等级；保留辅助监管声明 |
| 领导摘要 | 可选且位于正文之前；覆盖检查、风险、费用、变化、对标、重点检查和建议；无可靠参照时明确说明 |
| 一、机构基本情况 | 必选；1.1 基础信息表、1.2 总体结论及六项核心指标、1.3 范围内全部有效检查倒序表 |
| 二、历次风险变化 | 可选；2.1 折线、最高/最低/最大变化批次及节点信息；2.2 按检查类型比较次数、风险和费用 |
| 三、重点风险分析 | 可选；3.1 归因及重复/连续变化；3.2 八类行为费用和演示贡献独立标尺；3.3 行为×就医类型矩阵；3.4 项目前五及明细 |
| 四、横向对标分析 | 可选；全区、同结算等级或指定机构；4.1 排名、分位图；4.2 风险/总额/次均表；4.3 差异及缺项说明 |
| 五、重点检查概览 | 可选；按照风险、变化、费用、重复行为和未办结规则识别，展示批次和依据 |
| 六、检查办理情况 | 可选；6.1 数量、办结率与对比图；6.2 未办结清单、阶段、进入时间及停留天数 |
| 七、监管建议 | 可选；7.1 近期处置、7.2 持续监测、7.3 后续检查；建议关联具体行为、项目或批次 |
| 八、数据范围与指标说明 | 必选；8.1 时间、数据来源和生成信息；8.2 指标公式、阈值、单位、时效、排名与缺失处理 |

可选模块未勾选时不进入目录、正文和导出文件；先筛选模块，再按实际章节顺序连续编号，小节编号同步调整。仅固定内容时为“一、机构基本情况”“二、数据范围与指标说明”，对应小节为1.x、2.x。领导摘要不参与章节编号。领导摘要不再放在报告尾部。报告卡目录不再出现 `1. 1、` 的重复编号。

## 一致性与数据口径

`buildPortraitReport` 为唯一报告模型，预览、Word、PDF 均消费该模型。报告生成时间在生成或修订时固定，预览和导出不重复取不同时间。正文、表格和图表使用相同筛选后的检查集合。

- 风险均分为所选范围内单次值的算术平均；当前风险等级来自机构最新评级，两者明确区分。
- 最新检查为所选范围内检查时间最近的记录。累计及次均费用统一为万元，保留两位小数。
- 对标机构使用同一时间及检查类型。指定机构范围仅含目标及指定对照机构，不再先算全区排名后仅展示两家。并列同名次，分位＝名次÷有效参照机构数。
- 形成结果＝已办结；其余＝未办结；停留时间以演示快照日减进入阶段时间计算。
- 项目、评级和费用仍为本地演示数据。正式评分贡献、险种、整改结论或项目行为关联缺失时保留模板位置并说明“未接入／待核验”，不填入虚构正式业务事实。
- Word 保留可编辑正文和原生表格，图表嵌入图片；PDF 按章节和内容块分页，表格分块重复表头。

## 验证
