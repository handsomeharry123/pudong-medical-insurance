# 医小宝智能体悬浮入口：参考项目对照与验收

参考项目：`/Users/harry/Desktop/CC_TEST/agent-system 2`，仅只读参考。
参考实现：`src/pages/agent-center/smart/AgentAssistant.tsx`、`AgentRobotIcon.tsx`、`src/styles/global.css`。
适用模块：医疗机构监管履历画像的列表、机构详情、检查详情。其他模块不挂载入口。

## 功能对照

| 参考功能 | 当前实现与业务适配 |
| --- | --- |
| 64px 机器人，默认右下角偏移24px | 使用现有同源 SVG 品牌形象，名称为医小宝 |
| 拖拽、3px 点击阈值、Pointer Capture、边界夹紧 | 均支持，拖动不唤起对话；鼠标、触控共用 Pointer Events |
| 位置记忆、刷新恢复、窗口尺寸变化校正 | 本项目独立 localStorage 键 `pudong_assistant_pos_v1` |
| 欢迎气泡跟随机器人，关闭和8秒自动收起 | 支持；实际高度经 ResizeObserver 测量并夹紧视口 |
| 状态标签直接处理 | 全区页高/中/低风险标签直接同步机构列表的筛选条件及分页 |
| 迷你清单、记录操作、查看全部 | 全区页展示前三家高风险机构；机构页展示前三条未办结检查，可进入对应详情 |
| 非模态对话窗口，不影响背景页面 | 右24px、底40px，480×660，和参考源码的实际常量一致；机器人位置不影响窗口位置 |
| 标题机器人、关闭保留会话、键盘交互 | 收起后保留消息和输入；支持Enter发送、Shift+Enter换行、中文输入法和Esc关闭 |
| 呼吸、招手、思考、消息跳动、红点、收起动作 | 复用机器人动画；异步解析在收起状态完成时增加未读，打开清零；尊重减少动态效果设置 |
| PDF/图片上传、30MB限制 | PDF实际读取前30页文本并匹配机构；图片可预览。格式错误、超限、损坏PDF明确反馈，失败可重试 |
| 拖入自动唤起、窗口高亮、松开上传 | 页面级文件拖拽事件，遮罩提示；仅消费文件拖入，不消费文本拖拽 |
| 粘贴/输入URL识别 | 独立链接输入，HTTP/HTTPS校验，识别平台机构代码并衔接画像分析 |
| 语音录制和转写 | 支持浏览器语音识别，结果先填输入框；不支持时明确进入参考项目的演示流程，不虚构真实录音结果 |
| 当前页面欢迎与场景隔离 | 携带机构代码/批次，换页面重新建立上下文，不混用机构 |
| 智能结果卡和后续动作 | 复用监管分析引擎；为保持480px浮窗可读性，复杂分析通过“展开分析视图”打开宽抽屉；报告模块选择可直接交互 |

## 接入边界

参考项目中的机构接入注册、预填采纳、项目审计和告警审批等业务依赖其原有表单和权限，不属于当前监管画像模块；此处将这些入口适配为风险筛选、机构/检查导航和监管分析。
参考项目的图片OCR、网页抓取和语音功能包含mock。当前未接入图片OCR及远程抓取服务，界面明确说明能力状态，不将文件名当作真实识别结论、不生成虚假的业务字段。PDF文本提取和支持浏览器上的语音识别为实际处理。
