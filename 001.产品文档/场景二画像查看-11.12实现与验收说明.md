# 场景二：画像查看（11.12业务文档对照）

依据：《浦东新区医保智能体设计（业务侧）-11.12-V1.0》场景二。

## 业务路径与实现

| 分支 | 业务行为 | 实现 |
| --- | --- | --- |
| A 机构选择与画像 | 名称／代码联想、联动补全、查询、重置；唯一匹配、多匹配、无结果；先呈现画像 | `PortraitView.tsx` 筛选卡与画像；`portrait.ts` 匹配与概览 |
| B 纵向演变 | 风险趋势、检查类型汇总、关键变化点、最近变化摘要 | 趋势、类型汇总、变化列表；继续解释进入C，查看检查进入E |
| C 风险归因 | 整体归因→行为、就医属性、项目、历次检查 | 累计费用构成、行为×就医类型热力表、险种与本异地；关联检查可选 |
| D 排名与对标 | 全区、同结算等级、指定机构；风险值、总额、次均；名次与分位 | 继承机构与时间范围，按所选指标计算排名；差异原因转C，相关检查转E |
| E 检查定位与概览 | 最近一次、最高风险、批次、待选择列表→核心摘要→完整详情 | 摘要保留在场景二；点击完整详情后携带机构代码、批次号进入场景三 |
| F 建议与报告 | 三级建议、关联检查；固定基础＋可选模块；最少补问；版本修改 | 推荐勾选、全选、恢复推荐、时间范围；对标缺条件时补问；预览与导出复用现有能力 |

## 指标与状态约定

- 机构当前风险等级、历次风险值算术均分、最新单次检查风险值分开呈现。
- 费用以万元、两位小数呈现；风险值两位小数；排名同时给出名次、参照组数量和分位。
- 默认全部有效检查；显式年份或起止日期进入后续分析上下文。
- 切换机构时清理原机构的筛选、比较和报告状态。
- 报告基础内容始终保留；未选择模块不进入正文；领导摘要从正文提炼。
- 报告调整产生新版本；历史对话中的报告卡保持原有上下文，可重新查看。

## 数据边界

当前为前端演示，机构、检查及费用均使用仓库演示数据。未接入真实机构档案、评分引擎或违规项目凭证。费用构成沿用演示模型，不将费用占比表述为正式风险贡献；缺少真实项目明细时提示数据不足，不虚构具体违规项目。正式业务验收仍需接入真实服务，核验评分贡献、项目明细、检查有效性及归因证据。
