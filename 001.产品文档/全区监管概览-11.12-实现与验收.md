# 场景一：全区监管概览 — 11.12 实现与验收

依据：《浦东新区医保智能体设计（业务侧）-11.12-V1.0》场景一。产品名称沿用系统现有“医小保”，文档欢迎语中的“医小宝”统一为医小保。

## 业务流程对照

| 文档节点 | 实现行为 |
| --- | --- |
| 欢迎语 | 展示支持的风险等级、结算等级、时间范围、监管阶段，以及 A/B/C/D 四个独立快捷问题 |
| 1-A | 评级机构总数、三类风险机构数、环比变化、风险占比环形图、历年数量折线；仅概览卡设置全区监管大屏“查看详情”入口 |
| 2-A1 → 3-A1 | 默认 2023—2026 年；支持指定年度范围；展示三类机构数量、同比及最大变化年度；选择年度后查看年度高风险机构、年度风险值、检查次数及较上年变化 |
| 2-A2 | 按低→中→高比较相邻月评级，统计上升、下降、不变；变化表上升优先，显示前后等级、风险变化、新增高风险标记 |
| 2-A3 → 3-A3 | 左侧浦东机构风险点位示意，右侧高风险数量前五区域及高风险率；地址待匹配单列；区域筛选继承至机构名单 |
| 1-B → 2-B1/2-B2 | 高风险前五与本月上升机构双列表；分别进入全部高风险或上升名单，新增高风险单独标记 |
| 2-B3 → 3-B3 | 重点范围＝高风险与本月风险上升机构的并集；按年度有效检查统计违规行为、就医类型和项目；前五风险贡献横向柱图；选择行为后继承重点范围筛选机构 |
| 1-C → 2-C1 | 按结算等级展示风险构成堆叠柱图与机构数、高风险率、平均风险值、上升数对比表；高风险率和平均风险值分别说明 |
| 3-C1 / 2-C2 | 支持一级、二级、三级及 1/2/3 级自然语言；直接筛选所选等级，无需先完成对比 |
| 2-C3 → 3-C3 | 各等级年度平均风险值折线、高风险率及同比表；选择年度和等级后，比较上一年度风险值及等级，筛选风险上升机构 |
| A/B/C 机构汇合 | 选择机构先停留场景一，展示当前风险、历次均分、最新检查分、主要风险、最新检查及阶段；C 分支补充同等级排名；点击“查看完整机构画像”进入场景二并保留机构代码 |
| 1-D | 按年度和检查批次统计四阶段数量；分段矩形条展示办结/未办结数量与占比；形成结果＝已办结，其余＝未办结 |
| 2-D1 / 2-D2 | 检查列表按阶段停留时长降序；继承年度、指定阶段、检查类型；指定阶段回答数量和平均时长，支持查询形成结果阶段 |
| 2-D3 | 未办结检查按停留天数降序取前五，使用编号文字列表，不绘制图表；按配置或用户指定参考天数标记超期 |
| 3-DI | 选择批次先展示检查核心摘要；包含机构、批次、检查类型、风险值、风险等级、费用、主要行为、当前阶段；点击“查看单次检查详情”进入场景三并保留机构代码和批次号 |

## 数据口径与接入边界

当前为本地演示应用，未连接真实业务数据库。演示评级、年度记录、街镇和坐标均在结果卡中明确标记。文档示例的 386 次检查等数字不直接作为回答，实际展示由项目演示数据计算。

- 机构统计按机构代码去重；当前评级来自现有机构样本，历史年度评级由年度演示快照适配器提供。接入真实接口时须改用当年最后一次有效评级，并使用当年有效结算等级。
- 机构综合评级风险值与最新单次检查风险值分开展示；年度名单使用年度评级风险值，当前名单使用最新检查风险值。
- 月度上升依据相邻月风险等级；年度上升依据前后年度风险值或等级，避免混淆两个口径。
- 检查按唯一批次统计，停留天数以数据快照日减进入阶段日计算。演示快照为 2026-11-09，界面明确注明，不能视为当前实时数据。
- 无数据年度、无效批次或机构与批次不匹配时，不生成业务结论。
- 场景二、三由现有对应模块承接。本次不提交或推送 GitHub，也不部署远程环境。

## 验收

运行：在 `002.前端代码` 执行 `node tests/district.e2e.mjs`（开发服务默认 http://localhost:3001）。覆盖四条分支、月份和年度变化口径、结算等级解析、区域/行为范围、机构与批次跳转、空结果和错误批次；同时检查图表渲染与手机端横向溢出。
