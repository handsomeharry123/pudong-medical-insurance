# 医疗机构监管履历大屏 V1.0 实现与验收

依据：《医疗机构监管履历大屏-需求说明- V1.0.md》。原始需求文件保持不变。

## 已实现功能

| 区域 | 实现内容 |
| --- | --- |
| 顶部 | 数据覆盖周期、更新时间；无顶部全局筛选。监管机构、高风险、风险上升、累计检查、违规费用5项指标。 |
| 自动轮播 | 可开关，开启后03地图/机构列表每8秒切换；悬停图表、操作筛选、键盘焦点、机构详情展开时暂停，结束后8秒恢复。 |
| 指标联动 | 点击监管机构打开全部机构列表；点击高风险筛选03，再次点击恢复地图初始状态。 |
| 01 风险结构 | 数量柱状图、占比环形图、结算等级100%堆叠条；悬停展示机构数和占比。图例可联动03风险筛选。 |
| 02 风险趋势 | 月度、季度、年度折线图；悬停展示统计期、等级、数量、较上期变化。 |
| 03 地图/列表 | 浦东新区行政区边界，124个区内模拟点位；颜色表示风险等级，半径随违规总额增大。地图点位支持悬停、点击和键盘选中；列表按风险等级或最新检查值排序并自动滚动。 |
| 03 摘要 | 机构名称、代码、结算等级、风险等级、最新风险值、历次均分、违规总额、检查数、未办结数、主要维度；外部点击或关闭按钮收起。机构画像与历次检查继承机构代码。 |
| 04 进度 | 仅网审分工、检查实施、调查取证、形成结果四阶段，显示数量、状态、平均耗时；年/季/月已办待办双色比例条含数量、占比和口径。 |
| 05 TOP10 | 风险等级优先、同等级按最新检查值降序；显示代码、风险、检查值、较上期变动；循环滚动，悬停和键盘操作时暂停。 |
| 06 违规行为 | 8类行为的总体费用与占比环形图；悬停可见金额、机构数、检查数；不提供次均切换。 |
| 07 违规项目 | 项目总额与次均分别降序TOP5；次均分母为涉及该项目的有效检查次数；悬停展示完整名称、编码、金额。 |
| 08 智能总结 | 3条客观结论，随03模式/风险筛选、01展示口径、02趋势周期、04案件周期、07总额次均同步更新；支持重新生成，不提供原因臆断或监管建议。 |

## 最新口径与演示数据

本次需求优先于此前对话场景中的六阶段说明。共享检查数据统一为四阶段，“形成结果”为已办结，其余三个阶段为待办；对话中的检查状态、列表、来源与报告同步使用最新状态。原来未完结的示例流程调整为相应的检查实施或调查取证，避免同一批次在大屏和对话中状态不一致。

- 演示快照：2026-11-09；覆盖2022-01-01至该日。
- 机构124家，高/中/低风险为12/28/84家；风险上升5家，其中2家升至高风险。
- 有效检查135次，年度新增130次；当前未办结37次，涉及34家机构。
- 全周期已办结98次；2026年度已办结93次、待办37次；2026年11月已办结21次、待办5次。全周期阶段卡与年度办理条的时间口径不同，均在卡片内说明。
- 违规费用总额11,097,540元，行为金额、项目金额均能汇总回总额。
- 覆盖率100%以本演示档案中的124家有效纳管机构为基数，不代表浦东新区真实机构覆盖率。
- 点位坐标、项目明细、月/季风险快照、阶段耗时与上期风险值变动均为虚构演示数据，非真实监管记录。

## 深蓝科技风与一屏布局（2026-11-10）

参考用户提供的视觉样图，采用深蓝背景、青色描边、切角标题和发光数字，风险色仍区分高/中/低。只对数据大屏路由应用深色导航，不改变医小保工作区的主题。

布局使用视口高度分配顶部标题、5指标、三列核心区、底部三卡和口径说明，不依赖整页缩放或隐藏PRD指标。常用桌面分辨率下无页面横向/纵向滚动；在较矮视口中将01图例置于图旁、04阶段字段并排，保证数值、状态和平均耗时不被裁切。03机构列表、05排名按PRD在各自卡片内滚动。

PRD展示形式保持：01数量柱图/占比环图/结算等级100%堆叠条；02三风险折线；03地图/机构列表与摘要；04四阶段+双色案件条；05自动滚动TOP10；06八类行为总额环图；07总额/次均横向TOP5；08三条客观总结与重新生成。

一屏布局验收覆盖1920×1080、1600×900、1440×900、1366×768、1280×720、1280×640、1280×600；校验页面无滚动、8个视图边界、阶段字段、八行为图例和总结内容完整。窄屏手机保留可读的纵向查看模式。

布局截图位于`/tmp/pudong-history-style-qa/`，测试入口为`tests/dashboard-layout.e2e.mjs`。

## 可读性与立体地图调整（2026-11-10）

- 06环形图扩大外径与内圈，内径比例调整为78%，金额完整显示`1109.75`，白色数字取消强光晕，单位另行展示。图例提高字号与对比度，8类行为均保留；内圈文字宽度纳入专项校验。
- 地图使用同一真实行政边界的几何挤出与斜视投影，增加实体侧面、光照、底部阴影和表面网格。此为地理边界立体可视化，不是卫星影像，挤出高度不代表真实地形；机构点位仍为区内虚构演示坐标。
- 增加边界流光、表面扫光、高风险点位呼吸及底部轨迹动画；点位悬停/选择时暂停动效，支持手动暂停与立体/平面切换，并遵循减少动态效果的系统设置。
- 提高标题、KPI、图例、趋势刻度、项目名称、排名和总结的字号与对比度；弱化重复的装饰描边。低高度视口以单行四阶段卡及同行风险图例减少空间挤压。
- 列表启动前停留1.5秒，降低滚动速度，悬停及键盘操作继续暂停，便于阅读。
- PRD五指标、01—08视图及原有统计和业务下钻不变；继续验证七种桌面尺寸的一屏展示。

新增专项测试：`node tests/dashboard-map.e2e.mjs`，校验动画像素变化、暂停/恢复、平面切换、筛选、键盘点位选择、减少动态效果与环形图文字容纳。截图保存在`/tmp/pudong-map-3d-qa/`。
