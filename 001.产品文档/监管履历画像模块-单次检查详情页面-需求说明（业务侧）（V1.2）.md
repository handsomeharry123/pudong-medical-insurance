### 二、下部三个页签

下部设置三个页签：办理进度页签、数据分析页签和违规项目明细页签。

#### 1.办理进度页签：

该页签在监管流程的任何状态下均可使用。

1. 监管流程进度条

横向展示完整的10个阶段：

> 数据筛查 → 网审分工 → 实施网审 → 任务派发 → 检查实施 → 调查取证 → 形成结果 → 结果告知 → 机构反馈 → 提出处理意见
> 

阶段状态区分为：

- 已完成：蓝色或绿色；
- 当前阶段：主题色高亮；
- 未开始：灰色。

点击任一已完成阶段或当前阶段，下方展示该阶段详情。

1. 当前阶段详情

通用字段包括：

- 阶段名称
- 阶段状态
- 开始时间
- 完成时间
- 办理部门
- 办理人员
- 办理进度（比如材料待上传、等待机构补充说明、已补充凭证等）
- 相关材料

不同阶段可补充特有字段。例如调查取证阶段增加取证材料、待补材料；机构反馈阶段增加反馈时间和反馈意见。

#### 2.数据分析页签

注意：该标签页仅在该检查的监管流程为“形成结果”及之后阶段才可进入，否则设置为灰色，内容为空。

统一数据口径：

| **数据项** | **统一规则** |
| --- | --- |
| 有效检查 | 监管阶段为“形成结果”及以后，且检查结果已完成入库 |
| 违规费用 | 以检查最终认定的违规费用为准，保留两位小数 |
| 费用占比 | 当前分类违规费用÷本次检查违规费用总额×100% |
| 项目数量 | 按医保项目编码去重，不按项目名称去重 |
| 风险值 | 使用单次检查风险值，保留两位小数 |
| 风险等级 | 使用“单次检查风险等级”，区分高、中、低风险 |
| 空值 | 无数据时显示“—”，不使用0代替缺失值 |
| 当前检查 | 所有历史图表中始终突出显示，不随其他高亮交互取消 |
| 图表穿透 | 跳转违规项目明细时携带当前行为、项目、险种、就医类型等筛选条件 |

4.列表交互

- 默认按违规费用从高到低排序；
- 支持按违规费用、违规数量、医院单价和费用占比排序；
- 固定左侧“序号、医保项目编码、项目名称”；
- 中间字段允许横向滚动；
- 表头纵向滚动时固定；
- 默认每页20条，支持20／50／100条切换；
- 支持导出当前筛选结果；
- 无结果时提示“暂无符合条件的违规项目记录，请调整筛选条件”。

5.与数据分析联动

从数据分析页进入时自动携带筛选条件：

- 点击“重复收费” → 自动筛选行为认定为重复收费；
- 点击“超范围支付×门诊” → 自动筛选行为认定和就医类型；
- 点击“其他推拿治疗” → 自动带入项目名称和编码；
- 点击某险种 → 自动筛选对应险种。
