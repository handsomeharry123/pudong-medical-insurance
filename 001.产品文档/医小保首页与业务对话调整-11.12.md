# 医小保首页与业务对话调整

依据：《浦东新区医保智能体设计（业务侧）-11.12-V1.0》第五节。品牌统一使用“医小保”。

## 定位与入口

描述：面向医保业务的数据分析与监管助手。

首次进入及新建任务：展示完整初始欢迎语和四张业务模块卡片。医保数据分析开放；医保经办审核、集采计划执行进度跟踪、长护险监管保留说明及按钮文案，标记“建设中”并禁用。自然语言询问未开放模块时明确告知建设状态，提供已开放分析入口。

点击医保数据分析：展示二级欢迎语、医疗机构监管履历画像功能说明和“进入功能”。点击进入功能：展示场景欢迎语、三项指标和全区查询快捷问题。输入模块名称也可进入对应层级。“业务模块”可随时返回模块选择，新建任务恢复首次入口；历史会话保留原有对话。

## 指标与查询

| 指标 | 统计口径 | 点击结果 |
| --- | --- | --- |
| 高风险机构数 | 当前最新有效评级为高风险，机构代码去重 | 高风险机构名单，选择机构后查看摘要及画像 |
| 本月风险等级上升机构数 | 比较本月与上月有效评级，按机构统计上升 | 风险上升机构名单，选择机构后查看摘要及画像 |
| 未办结检查数 | 按检查批次统计，非“形成结果”为未办结 | 未办结检查名单，选择批次后查看检查摘要及详情 |

指标点击以默认全区上下文发起，避免被此前的机构、年份、结算等级等条件污染；名单中的后续追问继续使用现有上下文继承能力。生成过程中禁用入口及指标按钮。

当前为前端业务演示，三项指标从现有演示档案及检查集合计算，显示数据快照日期，不作为实时业务数据。取消缺少真实时序依据的装饰折线。生产接入需提供评级、历史月份对比、检查批次状态及统一数据时间；空值应展示“暂无数据”，不默认填零。

## 验收

运行 `npm run build` 验证编译；`node scripts/verify-home-entry.mjs`（本地服务 localhost:3001）验证三级入口、三个建设中模块禁用、指标对应12家/5家/37次演示名单、未开放业务提示及浏览器异常。
