# 场景三：监管履历查询 — 11.12 业务对照与验收

业务基线：《浦东新区医保智能体设计（业务侧）-11.12-V1.0.md》第470—706行。更新日期：2026-11-12。

## 产品流程

统一入口“监管履历查询” → 文档原版欢迎语与三个推荐问题 → 检索有效监管记录 → 展示条件、数量和记录清单 → 用户选择批次 → 风险分析 / 监管过程 / 历史情况 / 监管研判 → 报告草稿、预览修改、文件下载与指标明细导出。

机构风险与单次检查风险分开；全区及多机构记录检索不默认绑定示例医院；分析前必须确定批次。宽泛意图返回三个明确选项。机构、批次冲突及未知编号返回纠正提示。切换批次清空已完成分析和报告状态。

## 业务映射

| 文档流程 | 本次落地 | 数据边界 |
| --- | --- | --- |
| 记录定位 A—H | 机构名称/代码、多机构/全区、最新/全部、年/季度/月/近半年/日期区间、批次、阶段、单次风险、升降序/前N、检查类型、组合筛选 | 处理结论、整改状态、独立记录编号无字段时明确提示 |
| 模糊意图 I | 2—4个意图选项，缺机构/批次时引导选择 | 自然语言采用本地规则，非通用大模型语义理解 |
| 单次风险分析 | 概览、等级标准、费用构成、128项指标矩阵、按行为/就医类型/本异地穿透、来源查看 | 正式实际值、预警阈值、计算周期、评分明细未接入，不将非零金额认定为预警 |
| 监管过程 | 当前阶段、进入时间、停留天数、办理时限、承办部门 | 完整历史节点、真实分工、网审意见未接入；场景三不编造完成节点 |
| 历史情况 | 历次检查、风险等级分布、指数趋势、费用及行为对照、参照机构对标 | 演示各批次行为比例相同，不宣称发现新增违规；整改待核实 |
| 监管研判 | 当前问题、费用依据、核查方向及材料建议、辅助研判边界 | 未配置正式关联规则、综合优先级评分，不自动生成正式监管认定 |
| 材料生成 | 已完成分析与缺项提示、章节选择/排序、精简摘要、版本及修改要求、预览、Word/PDF按钮 | 当前支持规则化章节调整；自由段落改写、任意字段选择及真实版本差异比较仍待扩展 |
| 明细导出 | 当前批次128项指标，继承筛选，生成真实.xlsx文件 | 阈值与实际测算值、预警结果缺失标注“未接入”；项目仍为演示数据 |
